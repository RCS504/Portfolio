# Portfolio

My personal portfolio website, built with HTML, CSS, and JavaScript.

## About

A single-page portfolio showcasing who I am, my projects, and how to get in touch. Built by Huzaifa Amir, a BSc Computer Science student at Queen's University Belfast.

## Sections

- Header: name, tagline, navigation
- About: brief background
- Projects: Airline Booking System (Java) and Food Aid Distribution System (HTML, CSS, JavaScript, PHP, MySQL). JavaScript toggles between them.
- Skills: technologies I work with
- Contact: how to reach me

## Built with

- HTML5
- CSS3
- JavaScript

## Running locally

Clone the repo and open index.html in your browser. No build step required.
